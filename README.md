Superstore Sales Analysis Dashboard

Project Overview

This project analyzes Superstore sales data using Tableau Desktop. The goal is to understand sales performance, profitability, regional performance, and monthly sales trends through an interactive dashboard.

Dashboard Preview

The dashboard provides a visual overview of business performance with interactive regional filtering.

Key Performance Indicators (KPIs)

KPI| Result
Total Sales| ₹2.33M
Total Profit| ₹292.30K
Total Orders| 5,111
Profit Margin| 12.6%

Dashboard Features

- Sales by Category: Compares sales across Technology, Furniture, and Office Supplies.
- Profit by Region: Compares profitability across four regions.
- Monthly Sales Trend: Tracks monthly sales performance.
- Interactive Region Filter: Allows users to filter dashboard charts and KPI cards by region.
- KPI Cards: Displays total sales, total profit, total orders, and profit margin.

Key Business Insights

1. Technology is the highest-selling category.
2. West region generates the highest profit.
3. East region ranks second in profitability.
4. November records the highest monthly sales.
5. Overall profit margin is approximately 12.6%.
